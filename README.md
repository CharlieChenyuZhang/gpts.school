# gpts.school
gpts.school is an early experiment in building an AI-native university powered by LLMs.

I originally started it as a learning hub for Web3: helping more people read and discuss foundational whitepapers, build first-principles understanding, and develop the confidence to write their own perspectives and proposals. Over time, that same goal evolved into a broader vision: an AI-assisted learning environment that lowers the barrier to deep reading, structured thinking, and producing original work across topics.
